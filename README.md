# Кадр

Версия 0.11.0: обновлённые главная, настройки, карточки и медиатека. Быстрые действия истории, сброс фильтров, поддержка крупного текста и сохранение фокуса TV. Все личные функции 0.10 сохранены.

Android-приложение для фильмов и сериалов с историей, избранным и продолжением просмотра. Android 8.0 и новее.

## Android TV, приставки и проекторы

Есть отдельный TV-интерфейс с навигацией пультом. На AOSP-приставках (в том числе X98K) и проекторах (в том числе Umiio Q2) при необходимости выберите «Настройки → Приложение → Интерфейс → TV / проектор». Поддержка конкретной прошивки требует проверки на устройстве.

В плеере: OK — воспроизведение/пауза; ←/→ — перемотка; ↑ — меню источника, серий и масштаба; ↓ — информация; Назад — возврат.

## Реклама

Всплывающие окна блокируются. Фильтр скрывает известные рекламные баннеры и запросы, его можно отключить для проблемного источника. Полное удаление видеорекламы внутри потока не гарантируется.

## Обновления

Приложение использует публичный HTTPS-файл [update.json](https://github.com/GEKSOD/kadr-updates/releases/latest/download/update.json). APK проверяется по SHA-256, версии, имени пакета и совпадению подписи с установленным приложением.

Репозиторий служит хранилищем выпусков. Фильмы и сериалы здесь не размещаются.
